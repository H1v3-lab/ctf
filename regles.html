Le principe

L'Arène est un CTF de type jeopardy : chaque challenge cache un flag au format SAKOI{...}. Tu télécharges les fichiers, tu résous l'énigme, et tu soumets le flag. Chaque flag correct te rapporte des points et te fait monter au classement.

Jouer

  1. Choisis un pseudo sur la page Challenges. Pas de mot de passe, pas d'e-mail : ton identité tient dans un jeton gardé par ton navigateur.
  2. Ouvre un challenge, télécharge ses fichiers, résous-le avec tes outils.
  3. Soumets le flag. S'il est correct, les points s'ajoutent.

Les challenges web sont fournis sous forme de dossier à lancer en local (par exemple avec Docker) : rien de vulnérable n'est exposé sur Internet. Tout se résout sur ta machine.

Ce qui est permis

  • Tous les outils et toutes les techniques sur les fichiers du challenge, sur ta propre machine.
  • Travailler en équipe, partager des idées — mais pas les flags.

Ce qui est interdit

  • Attaquer l'infrastructure de l'Arène (ce site, l'API, Cloudflare, GitHub) ou le domaine sakoi-cyber.me. Les challenges sont dans les fichiers, pas sur le serveur.
  • Le brute-force de l'API de soumission (le nombre d'essais est limité).
  • Publier les flags ou des writeups complets tant qu'un challenge est actif.

Vie privée

L'Arène ne stocke que ton pseudo, tes résolutions et ton score. Aucune adresse IP, aucun cookie, aucun pistage. Le code du site et de l'API est ouvert.

Une faille dans l'Arène ?

Si tu trouves une vraie faille dans la plateforme elle-même (pas dans un challenge), c'est un bonus : écris-moi à security@sakoi-cyber.me, voir la politique de divulgation.
